PROJETO DESENVOLVIDO PARA WINDOWS 11 COM PYTHON 3.13.14<br>
NECESSÁRIO INSTALAR O OLLAMA. https://ollama.com/download/windows<br>
A CONFIGURAÇÃO DE AMBIENTE É FEITA DE FORMA AUTOMÁTICA, BASTA RODAR setup.bat E ESPERAR FINALIZAR

RESUMO DO SCRIPT
1. CRIA UM AMBIENTE VIRTUAL EM /venv
2. DEFINE VARIÁVEIS DE AMBIENTE PARA O BUSCAR OS EXECUTÁVEIS DO PYTHON, PIP E HUGGINGFACE DE DENTRO DO AMBIENTE VIRTUAL
3. INSTALA AS DEPENDÊNCIAS
4. BAIXA O MODELO SCAPY pt_core_news_sm
5. BAIXA OS MODELOS BAAI/bge-m3 E facebook/bart-large-cnn DO HUGGINGFACE
6. BAIXA O MODELO qwen3.8:27b DO OLLAMA

O SCRIPT NÃO DESATIVA O AMBIENTE VIRTUAL AO FINAL DA EXECUÇÃO. ISSO É PROPOSITAL: AO FINAL, O AMBIENTE ESTÁ PRONTO PARA SER UTILIZADO

PARA RODAR:
1. EXECUTE OS SCRAPPERS PARA ALIMENTAR O BANCO DE DADOS
2. RODE OS CONVERSORES DE BRONZE PARA SILVER E SILVER PARA GOLD PARA TER EMBEDDINGS NA CAMADA GOLD. ASSIM O MODELO LLM PODE UTILIZAR AS NOTÍCIAS
3. RODE `python -m main {promp aqui}` E PERGUNTE ALGO PARA O MODELO

EXEMPLOS:
1. RODAR SCRAPPER DE NOTÍCIAS DO G1 SOBRE POLÍTICA
`python -m scrappers.g1.politica`
2. CONVERTER AS NOTÍCIAS DE BRONZE PARA SILVER
`python -m jobs.converter_noticia_para_silver`
3. CONVERTER NOTÍCIAS DE SILVER PARA GOLD
`python -m jobs.converter_noticia_para_gold`
4. PROMPT PARA O MODELO
`python -m main "resumo do resultado do primeiro turno da eleição presidencial do Brasil em 2026"`
